# Curso de Libras para Contexto Católico

Plataforma digital do curso de Libras da GEB.

**Domínio:** cursodelibras.grupoeduardabispo.com.br

## V1
- sem login e sem Supabase;
- progresso salvo localmente no navegador;
- trilha principal em quatro unidades;
- anexos preservados como materiais independentes;
- busca por palavra/página nos anexos indexados;
- estrutura preparada para vídeos;
- práticas com destino ao Google Drive.

A plataforma é uma transposição pedagógica digital do acervo: transformar quando houver ganho pedagógico, preservar o original quando necessário e submeter decisões pedagógicas ambíguas à responsável pelo curso.

Veja `docs/DIRETRIZES-DO-PROJETO.md`.
